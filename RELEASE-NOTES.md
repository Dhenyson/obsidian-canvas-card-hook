Canvas Card Hook turns Canvas cards into clickable navigation shortcuts.

- Create hook cards using **Add hook** in the native context menu.
- Copy a destination card link or use **Ctrl+C**, then paste into a hook's target field.
- Click the arrow to jump with native **Zoom to selection**.
- Navigate to cards in the same Canvas or another Canvas in the same vault.
- Keep normal **Ctrl+C / Ctrl+V** card duplication on the Canvas.
- Edit in a comfortable temporary 380 × 260 card, then return to your chosen size.
- Keep the jump arrow centered on short cards.

**Compatibility:** Obsidian Desktop 1.14.4 or later. Mobile and compatibility with other Canvas plugins have not been verified.

**Privacy:** Offline operation, no telemetry, no external services, and no additional account required by the plugin.

**Validation:** 42 integration checks in Obsidian Desktop 1.14.4, four unit tests, and the official Obsidian lint rules.

Use the Community Plugins browser once the listing is approved. For manual installation, place the three attached runtime files in your vault configuration directory under `plugins/canvas-card-hook/`, then enable the plugin.
